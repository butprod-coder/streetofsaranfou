# Planches fournies par l’utilisateur

Les sources originales sont conservées dans `gustavax-user-source.png` et `wrestler-user-source.png`. Les versions de jeu `gustavax-user.png` et `wrestler-user.png` ont été détourées avec l’outil imagegen intégré pour remplacer le damier opaque par de l’alpha. Les anciennes planches ne sont pas écrasées.

## gustavax-user

Use case: background-extraction. Input image: edit target, user supplied exact sprite sheet. Remove ONLY the baked gray/white checkerboard background and replace it with real zero-alpha transparency in a PNG. Preserve every foreground character pixel, pose, facial expression, muscular anatomy, costume, outlines, crisp pixel art style and colors as closely as possible. Do not redesign, redraw, embellish or reinterpret the sprites. Preserve the original 4 columns by 4 rows, 16 poses layout and canvas proportions. All figures remain complete. No checkerboard may remain anywhere including enclosed gaps between limbs. Do not paint any new checkerboard or backdrop. Do not add floor shadows, text, effects, accessories or new poses. This is a careful cutout of the supplied sheet, not new character art.

## wrestler-user

Use case: background-extraction. Carefully cut out the EXACT twelve pixel-art muscular men in blue shorts from the supplied original image. The gray/white checkerboard is an unwanted opaque backdrop and must be DELETED, leaving actual zero-alpha transparency. Do not render a new checkerboard. Preserve pixelated foreground artwork, identical anatomy, silhouettes, blue shorts, sunglasses, poses and exact 4-column 3-row layout, landscape proportions. No smooth cartoon redraw, no changes to the men, no relighting. Transparent PNG with no background at all, including the holes between arms and legs. The only desired change is removing the checkerboard.
