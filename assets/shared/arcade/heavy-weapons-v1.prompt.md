# Armes lourdes et effets

Création avec l’outil intégré imagegen, puis suppression du fond avec ce même outil. Sprite atlas PNG avec alpha, 1536 × 1024, grille 3 × 3. Consommé par `heavyWeapons` dans `game/visuals.js`.

## Prompt de génération

Use case: stylized-concept. Asset type: transparent pixel art sprite atlas for a retro side scrolling street beat em up. Create ONE atlas with exact regular 3 columns by 3 rows, nine isolated centered sprites, generous transparent gutters, no text or labels. Read left to right top to bottom. Row 1: olive green bazooka tube facing right, industrial flamethrower gun facing right with orange tank, olive green hand grenade. Row 2: flying rocket facing right with short orange exhaust, horizontal cone of orange yellow flames pointing right, round bright orange explosion. Row 3: small gray smoke puff, larger orange explosion with sparks, fading dark smoke cloud. All sprites fully inside their equal cells. Crisp detailed 16-bit arcade pixel art, dark outlines, bright highlights, true transparent background. Guns only no hands no people. Landscape 1536x1024.

## Prompt de transparence

Remove ALL background including the dark gradient and colored ambient glow between sprites. Preserve the nine sprites, exact positions, exact 3x3 grid and all crisp outlines. Output genuinely transparent alpha everywhere between sprites, no matte no gradient no backdrop. Preserve flames and smoke as isolated sprites. Do not redesign.
