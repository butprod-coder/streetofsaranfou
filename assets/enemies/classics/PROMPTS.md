# Sprites des ennemis classiques

Mode : imagegen intégré. Références : anciens sprites pour l’identité, Bolorouet pour le style. Les PNG finaux sont dans ce dossier ; les sources générées restent conservées par l’outil. Tailles et poses : `game/classic-sprites.js`. Chaque planche contient 12 cellules (4 × 3), normalisées en 2048 × 1536 px.

Post-traitement technique local autorisé par l’utilisateur : retrait du faux damier connecté au fond, nettoyage des résidus neutres, détourage ciblé des espaces entre membres et accessoires, découpage et rangement sans redessiner les personnages. `scripts/SpriteCutout.cs` avec `enclosed=false` préserve les vêtements clairs ; `scripts/ClassicAtlas.cs` utilise les rectangles, graines de détourage et exclusions consignés dans `packing.json`. Validation sur fond sombre dans le navigateur pour toutes les poses. Les sources générées d’origine ne sont pas supprimées.
